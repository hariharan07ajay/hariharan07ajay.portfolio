# Hari Haran — Professional Portfolio

## Structure
- `index.html` — main portfolio
- `assets/css/style.css` — responsive professional styling
- `assets/js/script.js` — navigation, credential tabs and certificate preview
- `assets/certificates/` — add your real certificate files here
- `assets/projects/` — project screenshots/assets
- `assets/images/` — profile photo and other images

## Before deployment
1. Replace the placeholder profile section with your professional photo.
2. Add your real resume as `assets/Hari-Haran-Resume.pdf`.
3. Add real certificate files and update their filenames in `index.html`.
4. Replace GitHub, LinkedIn and email placeholders.
5. Add final project GitHub/live-demo URLs.
6. Test on mobile and desktop.
